# 🩺 Throat Cancer Healthcare Analytics Project

## 📌 Project Overview

This project is an end-to-end healthcare data analytics project focused on throat cancer.

The project uses a synthetic dataset of 5,000 patient records to explore demographic patterns, geographical distribution, risk factors, clinical characteristics, treatment patterns, survival and patient outcomes.

The analysis was completed using:

- Microsoft Excel
- MySQL
- Power BI

## 🎯 Project Objectives

The main objectives were to:

- Explore throat cancer cases across different countries and continents
- Examine age and sex distribution
- Identify common cancer subsites
- Analyse major risk factors
- Explore clinical stages and metastasis
- Examine treatment patterns
- Analyse survival months
- Compare patient outcomes
- Build an interactive healthcare dashboard

## 🗂️ Dataset

The dataset contains 5,000 synthetic records and includes variables such as:

- Patient ID
- Diagnosis year
- Country
- Continent
- Sex
- Age
- Cancer subsite
- Smoking status
- Alcohol use
- Areca nut use
- Betel quid use
- HPV status
- EBV status
- Clinical stage
- Tumour grade
- Metastasis status
- Treatment
- Outcome
- Survival months
- Health access
- Health insurance

> **Note:** This is a synthetic dataset created for educational and portfolio purposes. It does not represent real patient records or official cancer surveillance data.

## 🔎 Analysis Workflow

### 1. Excel

The dataset was first explored and prepared in Excel.

Tasks included:

- Data cleaning
- Missing-value inspection
- Category checks
- PivotTables
- Initial trend analysis

### 2. MySQL

SQL was used for deeper analysis, including:

- Case distribution
- Risk-factor analysis
- Clinical-stage analysis
- Mortality analysis
- Survival analysis
- Metastasis analysis
- Treatment analysis

Example analysis questions included:

- How does smoking status vary across patients?
- What is the mortality rate by smoking status?
- How does survival vary by clinical stage?
- How does the number of risk factors relate to advanced-stage cases?

## ⚠️ Important Interpretation Note

The analysis identifies patterns and associations within the synthetic dataset.

Association does not establish causation.

The results should not be interpreted as actual population-level cancer estimates.
